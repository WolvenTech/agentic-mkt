# n8n-workflow-builders

Suggested while discovering this repo's decided tools, ask-only until the
Human defines it.

## Discovery evidence

- `src/workflows/build-marketing-pipeline.ts` and
  `src/workflows/build-call-agent.ts` build the two n8n workflows; Code node
  logic lives in 27 `.js` files under `src/workflows/*/code-nodes/`.
- `integrations/marketing-pipelines/*.json` is generated by
  `pnpm build:workflows` and never hand-edited (`AGENTS.md`, Protected
  Surfaces §3); CI runs `pnpm build:workflows:check`.
- The generated workflows use 30 Code nodes, 13 ClickUp nodes, 11 IF nodes,
  6 HTTP Request nodes, and 2 GitHub nodes, on the self-hosted host
  `n8n.wolven.com.br`.
- `pnpm deploy:workflows` is a live command behind `pnpm vendor:gate`;
  `pnpm lint:code-nodes` lints the Code node sources.
- Decisions: ADR-004 (staged workflow), ADR-010 (best-effort dedup in
  workflow static data), ADR-011 (provider routing in the Call Agent).
